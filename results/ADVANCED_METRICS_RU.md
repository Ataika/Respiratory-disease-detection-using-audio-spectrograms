# Advanced Metrics: ICBHI Score, AUC-ROC, ECE, Bootstrap CI

## Назначение

Закрывает три пункта, которые были явно в дизайн-споке (раздел «Метрики»)
и оставались на 0% реализации: официальный ICBHI Score, in-domain
AUC-ROC и калибровка (ECE). Считаются одним воспроизводимым pipeline:

```
scripts/export_val_predictions.py   → results/predictions/*.npz
scripts/compute_advanced_metrics.py → results/advanced_metrics/
```

Экспорт предсказаний отделён от подсчёта метрик специально: один и тот же
`.npz`-кэш используется и для метрик ниже, и для McNemar/DeLong тестов
между моделями (`tests` требуют парных предсказаний на одном и том же
val-сете — экспорт делает это один раз на модель, а не при каждом расчёте).

## ResNet50 (tuned), val set ICBHI (n=1119)

### ICBHI Score

| Se (sensitivity, abnormal) | Sp (specificity, normal) | ICBHI Score |
|---|---|---|
| 0.4079 | 0.7518 | **0.5798** |

Официальная метрика конкурса ICBHI 2017: Se — доля верно распознанных
патологических циклов (`crackle`+`wheeze`+`both` вместе), Sp — доля верно
распознанных `normal`. Разрыв Se vs Sp (0.41 против 0.75) — модель
намного увереннее на `normal`, чем на патологии — согласуется со всеми
остальными результатами проекта (confusion matrix, per-class F1, Grad-CAM
пример на `both`).

### AUC-ROC (in-domain, macro one-vs-rest)

| | AUC |
|---|---|
| macro (все 4 класса) | **0.7430** |
| normal | 0.7266 |
| crackle | 0.7364 |
| wheeze | **0.8328** |
| both | 0.6762 (минимум) |

`wheeze` разделяется лучше всего, `both` — хуже всего, что логично: это
смешанный класс без собственного акустического паттерна, а комбинация
паттернов двух других классов.

### ECE (Expected Calibration Error) и калибровочная кривая

**ECE = 0.1895** — заметная разбалансировка между уверенностью модели и
её реальной точностью. `results/advanced_metrics/resnet50_reliability_diagram.png`.

Самое показательное: в бине самой высокой уверенности (0.9–1.0, 352
примера — почти треть всего val-сета) средняя заявленная confidence —
0.956, а реальная accuracy — только 0.685. Модель систематически
переуверена именно тогда, когда увереннее всего — классический паттерн
overconfidence современных глубоких сетей, хорошо задокументированный в
литературе по калибровке (Guo et al., 2017) — стоит явно сослаться на
эту работу в Related Work при обсуждении ECE.

### Bootstrap 95% CI для macro F1 (n=2000 resamples)

| point estimate | 95% CI |
|---|---|
| 0.4575 | **[0.4232, 0.4930]** |

Ширина интервала (~0.07) того же порядка, что и seed-to-seed разброс из
`MULTISEED_SUMMARY_RU.md` (~0.08–0.10) — два независимых метода
(бутстрэп на одной модели и multi-seed переобучение) сходятся к одному
выводу: точечная оценка macro F1 сама по себе не показывает, что модель
X «лучше» модели Y без учёта этого интервала.

## McNemar / DeLong (сравнение моделей)

Требуют предсказаний минимум двух моделей на одном val-сете — на момент
записи посчитано только для ResNet50. EfficientNet-B3 и AudioMAE
переобучаются (см. `PROJECT_LOG_RU.md`); как только чекпоинты готовы —
`export_val_predictions.py` + `compute_advanced_metrics.py` без
дополнительного кода дадут попарные McNemar (согласие/несогласие по
сэмплам) и DeLong (сравнение AUC на бинарной редукции normal-vs-abnormal)
тесты между всеми парами моделей.
