## 2. MC Dropout (uncertainty)

**Статус: было — 0% реализации → стало — рабочая, статистически
осмысленная проверка.**

`results/uncertainty/mc_dropout_resnet50_tuned.{txt,json}` +
`mc_dropout_entropy_hist.png`. N=30 стохастических forward pass на
sample, полный validation set (1119 записей).

| | mean predictive entropy |
|---|---|
| correct predictions | 0.5271 |
| incorrect predictions | **0.6445** |

**Главный вывод: uncertainty информативна.** Неправильные предсказания
в среднем заметно неувереннее правильных — то есть связка "модель не
уверена → нужно перепроверить у врача", центральная для медицинской
честности проекта (см. дизайн-спек, contribution #4), реально работает
на этой модели, а не просто задекларирована.

По классам средняя entropy растёт вместе со сложностью класса:
`wheeze` 0.554 → `normal` 0.571 → `crackle` 0.585 → `both` 0.631 —
модель наименее уверена именно там, где чаще всего ошибается.

Реализационная деталь для методологии: 30 стохастических проходов
считаются одним батчированным forward-вызовом (вход повторён 30 раз по
batch-размерности), а не 30 последовательными вызовами — математически
идентично, но на порядок быстрее на MPS.

## 3. Cross-domain: BRACETS (обновлено)

**Статус: было сделано раньше (AUROC 0.463) → пересчитано на новом
checkpoint (AUROC 0.509).**

| | старый checkpoint (июнь) | новый checkpoint (сентябрь) |
|---|---|---|
| Accuracy | 0.455 | 0.380 |
| Macro F1 | 0.404 | 0.366 |
| AUROC | 0.463 | 0.509 |

Обе версии независимо приходят к одному и тому же научному выводу:
**AUROC около 0.5 = обученная на ICBHI модель не переносит
диагностическую способность на BRACETS вообще**, что бы ни варьировалось
между конкретными прогонами (seed, порядок инициализации). Это
укрепляет, а не ослабляет исходный вывод — воспроизводимость самого
негативного результата на двух независимых checkpoint'ах делает его
надёжнее для текста диплома, а не подозрительнее.

## 4. Cross-domain: SPRSound (впервые)

**Статус: было — не оценивалось никогда → стало — есть первый результат,
и он хуже, чем BRACETS.**

`results/external/sprsound_resnet50_tuned.{txt,json,confusion.png}`.
1772 записи (парсер расширен на `valid`-сплит SPRSound, раньше читался
только `train`).

- Accuracy: 0.2314
- Macro F1: **0.1874** (хуже, чем BRACETS: 0.366)

Confusion matrix показывает конкретный механизм провала: модель
почти всегда предсказывает `crackle` (1064 из 1303 истинно-`normal`
записей размечены как `crackle`) — recall `crackle` 0.915, но ценой
почти полного игнорирования `normal` (recall 0.122).

**Гипотеза для Discussion:** SPRSound — педиатрический датасет (дети),
ICBHI — преимущественно взрослые пациенты. Разница в анатомии
дыхательных путей, частоте дыхания и, вероятно, в оборудовании записи
между китайским педиатрическим госпиталем (SPRSound, SJTU) и
изначальными клиниками ICBHI — более резкий domain shift, чем между
ICBHI и BRACETS (оба — взрослые пациенты, хоть и в разных странах).
Это самостоятельный, ранее неизвестный научный результат проекта.
